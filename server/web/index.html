How to send RFID scans from your ESP32

Append a new record using an HTTPS POST to:

https://lightlink-cbe74-default-rtdb.firebaseio.com/scans.json

JSON request body:

{
  "tagId": "E200001234",
  "receivedAt": {".sv": "timestamp"}
}

No login is required for this prototype. Use a new record for each scan; do not overwrite /scans. Firebase supplies the receipt timestamp. Return commands are available under /signal.

Live data from Firebase · Full scan history is loaded for this prototype · No wear counts are calculated yet.
